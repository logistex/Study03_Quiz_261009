## 앱의 기능

- 카테고리 4개(한국사, 세계지리, 과학, 예술과 문화), 카테고리마다 13문항. 한 판은 그 카테고리에서 무작위로 뽑은 10문항임
- 게임 모드 3개: 연습(순위표에 기록되지 않음), 스피드(문항마다 15초), 힌트(오답 2개를 지우고 맞히면 0.5점)
- 틀린 문제 다시 풀기, 모드와 카테고리별 순위표(브라우저의 localStorage에 저장)
- 문항마다 서로 다른 기관의 출처 2개를 해설 아래에 보임

## 실행하는 법

- 서버 없이 `index.html`을 브라우저로 열면 동작함
- `index.html?test`로 열고 개발자 도구의 콘솔을 보면, 앱 안의 자체 점검 결과가 나옴. 끝 줄이 `점검 통과: N개`이면 정상임
